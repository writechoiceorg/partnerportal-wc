title: "How to Add a Resource"
description: "This article will walk you through the steps on how to add content to your Resource Center."
---

Please make sure that your Resource Center has been set up before uploading content. *To learn more, check out this [article](https://help.partnerportal.io/en/articles/6932138-setting-up-the-resource-center).*

# Adding a Resource:

Click **Add Resource** under **Resources** on the left sidebar.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2381822882/39c0f7f3eaaac3151fc9c056c562/image.png?expires=1779111900&amp;signature=4390ce0a48368109b2aca0d0439166eb88b8e221ce5a2e370cb13f7d2fe55760&amp;req=diMvF8F8n4lXW%2FMW1HO4zRtW%2FMwHi5MnPMdelcw97E8%2FoOk8EUpuWUW93TqQ%0Ae%2B7jebbi%2BHFr2JoZTKA%3D%0A)

1. **Name Your Resource**
This name will be displayed to your Partners when they see the file.

2. **Add an Excerpt**
Optionally, you can add an excerpt to provide a summary about the resource, such as its benefits and uses, for excerpt-based layouts.

3. **Select a Category**
Choose which category you'd like this resource to be in. You can add a resource to multiple categories if needed.

4. **Add a Featured Image**
Click the "Upload Image" button under the Featured Image section at the bottom.

Please note, that if you do not upload a featured image, a default one will be placed.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2381828599/9efdfb3bf6b7ac78a8a5744b615e/image.png?expires=1779111900&amp;signature=dae448bdca5ec2eea837247f0e6c2fe7165b27f9d973e8d026a4b74063f6187d&amp;req=diMvF8F8lYRWUPMW1HO4zZdV8pP9taRLrBCjdi4yoEZGSXXD09N%2FJE5hzxof%0A1ANPi9ROluS3D3GJyIA%3D%0A)

# Uploading an Attachment:

1. **Select the Attachment**
Click the **Add attachment** option under the body of the resource.

  ![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2381833970/bae4cce81f27f6e91fea4650fc9c/image.png?expires=1779111900&amp;signature=3342844b8d45fcde62ec95a4a924d39057357b2091231a4cf96cd3152e834bc8&amp;req=diMvF8F9nohYWfMW1HO4zSQ%2FVunJI5KcV6%2BcP4MdR5mlcNS3CtgihypYL1zv%0AKm7m%0A)

2. We support various file types, including PDFs, Word Documents, PowerPoints, etc. However, depending on your browser, some files may automatically download if they cannot be displayed, which is common with PowerPoints or slideshows.

3. Add your File.

  ***Please note that the file size must not exceed 100MB.***

4. **Save Your Resource**
After your resource is uploaded, press the "Save" button.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2381839111/146da709c1ea9cbd3ecf73e93e39/image.png?expires=1779111900&amp;signature=53d59455477457d5bced67bbaa60e567f89ec0a25853a6dbf72c272d4c18b482&amp;req=diMvF8F9lIBeWPMW1HO4zaOlpYU%2BB5ELblExhIcJYdo2qnn9aMnzcoZUGcia%0AEG4gCDITpFRv7Gin3CM%3D%0A)

## Additional Notes:

- **New Partners**
If new partners are added to the portal, they will not see any uploaded content until they've been assigned to it, i.e., added to a group.

- **Content Visibility for All Partners**
If you want content to be visible to every partner, select the "All Partners" group.
