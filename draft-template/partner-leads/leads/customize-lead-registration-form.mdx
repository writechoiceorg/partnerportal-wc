## Add a new field

1. Go to **Leads** in the sidebar and select **Configure**.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388636749/16c8ffcd3217da9deb03a7e38a95/image.png?expires=1779111900&signature=e323b286bb581092a40e08faddd8d43a31d40a75a51c6a4976a421a06b9d8427&req=diMvHs99m4ZbUPMW1HO4zUjC9BeX3dfLUzzBAH%2B3uJLX86eL2fhtAUDR4pHq%0AqYG5fzLYEsGur36YMyc%3D%0A)

2. At the bottom of the lead fields list, click the **plus sign** to add a new field.
3. Choose a field type: **Text**, **Numbers**, **Picklist**, or **Large Text**.
4. Check the **Active** box to include the field on the Lead Registration Form.
5. If the field is required, check the **Required** box. Partners must complete required fields before submitting a lead.
6. Rearrange fields in any order as needed.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388640263/15883a2bd7102857e5e7161990b0/image.png?expires=1779111900&signature=4e6683162760894823112c97971b8a6b10ee0c03b690bbdad95549df2a4fd338&req=diMvHs96nYNZWvMW1HO4zeKqmFp%2F1CIuQWGynsmPAIX13r0sHWvnLLjeECFh%0A0pPG%2BnDs2z4%2FICui%2F3k%3D%0A)

<Callout type="info">
  To learn how to submit leads on behalf of partners, refer to [this article](https://help.partnerportal.io/en/articles/7045874-submit-a-lead-on-behalf-of-a-partner).
</Callout>

## Set field visibility

You can control which users see each field on the Lead Registration Form.

1. In the field's settings, go to the **Visibility** section.
2. Select one of the following options from the dropdown:

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388642772/cc670b4f9dbc88157efa275a5faf/image.png?expires=1779111900&signature=cd4e0edaf9745f8bc284ecefef1efc89319c79f059e8af3632be01c6767d98a1&req=diMvHs96n4ZYW%2FMW1HO4zdpDQ9TNGJaHmznSaFVRWYZruCwAG7wvrOf3XpI3%0ANYLKvtWekL8QftSY2GA%3D%0A)

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388644968/149dd852c813d3e49b07c30859ae/image.png?expires=1779111900&signature=6b44d0e4bd7b48d031e895fd3d8aceda6b7d525a94245fbb1de05bce95f6460e&req=diMvHs96mYhZUfMW1HO4zQZWmW2gv7TXTkRYkW%2BwmD9GyZ0cIB4%2FUBiZBkQ9%0ADGY%2Bj2f15%2FtCTvIqkZQ%3D%0A)

   - **All Users**: all partners and admin team members can see the field.
   - **Internal Use Only**: only admin team members can see the field; partners cannot.
   - **Select Partner Group(s)**: only the selected partner groups can see the field.

### To set visibility by partner group

1. Select **Select Partner Groups** from the dropdown.
2. Click **Manage** to find and select the partner group(s) of your choice.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388647261/9b992d62a02d70bc478ab567ca13/image.png?expires=1779111900&signature=25a5e482fe01dfe2660ca84da032612a507681c5c4b5e318d91e7ddd909e19ab&req=diMvHs96moNZWPMW1HO4zc%2FZswxjZkuom3%2BEG%2FIUEaa3QabuacVtXf6B4rKX%0AKnQP0n2fLKBXbxYpx7k%3D%0A)

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388648583/7e3a49abbead320de3b9c94cad58/image.png?expires=1779111900&signature=02b2f562354d551d6faf4ed32f0ba95eb2cc1c5d2f36921f4bb1a8c077590a9a&req=diMvHs96lYRXWvMW1HO4zcaEJoo6Vzx%2F9sFR26CsxtJ4rgIP1792PYv3z8tN%0AWHiIdQ1QEGPgAaF6Il0%3D%0A)

<Callout type="info">
  To use partner group visibility, you must first create partner groups. Learn how [here](https://help.partnerportal.io/en/articles/10034393-creating-partner-groups).

## Create a picklist

1. In the field's **Type** section, select **Picklist** from the dropdown.
2. Click **Edit Options**.
3. Click the **plus sign** to add picklist choices.
4. Click **Close** when finished.
5. Save your changes regularly to avoid losing progress.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388659984/6c2225f52ef5204c914ee2d8973d/2026-05-15_10-40-20+-1-.gif?expires=1779111900&signature=b8fe9e6cb1ffb1cc7f4d47598e73dfd7609a0122766d2e82bdd898428505d78e&req=diMvHs97lIhXXfMW1HO4zRJbdO3d75bASGlf6MEw43ysKjCVEAXg8PAcXQb2%0ALkFQAp4X3EODIiL5ouw%3D%0A)

<Callout type="info">
  To learn how to map custom fields to HubSpot, refer to [this article](https://help.partnerportal.io/en/articles/6977660-how-to-map-custom-fields-to-hubspot).
</Callout>

## Configure the Lead Type dropdown

The **Type** dropdown on the Lead Registration Form can be configured to match your use case. Common examples include:

- Type of lead (for example, "New Business" or "Existing Client")
- Type of partner
- Location of the partner
- Type of product

To configure lead types:

1. Find the **Type** field in the Lead Registration Form configuration.
2. Click **Edit Options** to add and manage your lead types.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388664763/62ed07b3c24a1af61676d07ffc45/image.png?expires=1779111900&signature=f3918bf0ecc4f493a367d578c0d454ce5a46ffda3566c5233fa0bb4959405e03&req=diMvHs94mYZZWvMW1HO4zXoMeQ8RMItEIkcD%2B%2F4sHeZE4pKkkP9yHjI8m4lN%0AQhAmc2Zk6T7a57Rw%2FrQ%3D%0A)

<Callout type="info">
  Partners can only select one lead type when submitting a lead. To allow partners to enter a different type, toggle on the **"Other option"**.
</Callout>

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388666062/4300c650a9c7e1d9436ad1e17453/image.png?expires=1779111900&signature=26dfb3a6bc0c2696b3a7445bca872831d6ef0c60ddd5e2385944f40a72b26c9a&req=diMvHs94m4FZW%2FMW1HO4zWu%2FDFaInfPZCKz6K0UwsDrMIKCJei8oq2CN4cWl%0A1eDBtC2KvQMmROxpoKI%3D%0A)

<Callout type="info">
  To map leads to different pipelines based on lead types, refer to the pipeline mapping article.
</Callout>
