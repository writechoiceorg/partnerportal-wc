<Callout type="warning">
  You can only import leads for **active** partners in your portal. If you don't have any partners set up yet, you won't be able to import leads on their behalf.
</Callout>

## Before you start

- You must have at least one active partner set up in your portal.
- Your CSV file must contain all **required** fields from your Lead Registration form. Optional fields won't trigger errors if missing.
- The bulk import tool does not check for existing leads. Confirm any existing leads before uploading your CSV to avoid duplicates.

---

## Import a CSV

1. Go to the **Leads** section in the sidebar and select the **All Leads** tab.
2. Click **Register Lead** and select **Import CSV**.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388707479/aa93ac43bbffb337c6b9eaefb8dd/image.png?expires=1779111900&signature=6ebdf3411e862f9964c680fd2ae48f6c1f79c720dc3027b41f9d2fbcad5203ec&req=diMvHs5%2BmoVYUPMW1HO4zVBUd077iiUVR7pwsmbrba%2ByGuBnYme%2Fz9BK%2BYCK%0AtzbDlhcvPvcIM4X64rw%3D%0A)

3. Download the CSV template provided, or upload your own file.

   > We only support CSV (comma-separated values) files.

4. After selecting your file, click **Import Lead**.
5. The system will check the file for missing required fields and mark them as errors.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388707928/708e3d6181bf8566aa8a337f99d4/image.png?expires=1779111900&signature=9af03014e079f9d917b7cf8ac05611c784e32b1fddafff47301a2758ccddd88f&req=diMvHs5%2BmohdUfMW1HO4zapyud1Bxa46S3SYcQAeaWPlYNjDABoir50xT1a8%0AMHIRrmnta8Pift%2FWgBE%3D%0A)

   - If errors are found, the file will **not** import until they are corrected.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388709301/ad574cd0358fa6f7755650cf15b3/image.png?expires=1779111900&signature=8c40b300c48f6ac08b861d384c0f938aa4696a7ccf2899bdc1908f423eb1944f&req=diMvHs5%2BlIJfWPMW1HO4zd8Giz4p6WvqRWePp0KJuGHY1AU9E48kLyJPB74N%0AR%2B1MSE0zkgCGMIUlwZo%3D%0A)

   - Each lead must be entered as a separate row.

6. Correct any errors in your CSV file and re-import.
7. Once no errors are found, you will see a confirmation message indicating a successful import.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388725146/7d5ca52709b5de7fa69a7a599d3a/image.png?expires=1779111900&signature=51aa153644092be6ace982a32eebcd4afb96922809e3260e8aa9d63287d7e3cc&req=diMvHs58mIBbX%2FMW1HO4zfoSfBgKyzAmUZody5fQnr9%2BKpwFHG3ZYpLkU88G%0Aw8LWSOQuToCROjpANEc%3D%0A)

8. Refresh your portal to see the newly imported leads.

<Callout type="info">
  All imported leads are placed in **Pending** status and require approval from the admin team.
</Callout>

## Find the Partner and Partner User ID

Partner and Partner User IDs are required fields when importing leads. Use them to associate each lead with the correct partner.

### As an Admin

1. Go to the **All Partners** tab.
2. Select the partner and find their unique ID in their partner details.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388711951/6b0faa0e51902567604dbf71ad45/image.png?expires=1779111900&signature=2f012919b990bef1ec6f73460ca44365aa6a29686bc2b80dd431747580f030ed&req=diMvHs5%2FnIhaWPMW1HO4zUFl8%2FuH8YwherOuZsqk04pf8psLdoiq0u6EV%2FpI%0AU1Uo56RZs5MnnW4Mlcg%3D%0A)

3. To associate a lead with a specific Partner User, scroll to the bottom of the partner's page to find the **Partner Users** list.
4. Copy the individual user's ID from the ID column, or click the **pencil icon** to edit the Partner User and find their ID there.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388714732/121736ce8fecd2688553ecfa71e6/image.png?expires=1779111900&signature=67ec5003b9e75fab047da3f7dafafa63c7f9b5e7ad84ac37b8006b3004919399&req=diMvHs5%2FmYZcW%2FMW1HO4zU7fSWlJDza5uSEkchTlRPB4cS6yvrIdJyPJ3qmI%0Am5hPVQVRYomNmzhpyzE%3D%0A)

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388716858/2965420e3a03992d0d6cd037f494/image.png?expires=1779111900&signature=b7cb5b9254344e1e40d63a357db21f9c6821f96f9dad5bb7a0899e07b6834ce6&req=diMvHs5%2Fm4laUfMW1HO4zTGkf7Prv1Fq9BpHDttlNxpqBrZ6LuXOjfvMD4Sp%0AvPM3d8695l5ezIsUQNw%3D%0A)

### As a Partner

1. Go to **Account** in the sidebar and select the **Team** tab.
2. Find the Partner User's unique ID next to their name in the ID column.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388721428/a0eb12eb094b876279a0bc8bd1a7/image.png?expires=1779111900&signature=c7c0493592f12049c389c18068c616277dd7ca579d679686a10fd60d1789c61b&req=diMvHs58nIVdUfMW1HO4zY2Sz9qsvj4AET6WzufbTN8UKrpDqC43zBB0b%2Fy1%0AHVFmIXEZo7YnMq4Xx7E%3D%0A)

<Callout type="info">
  If you are bulk importing leads for yourself, use your own unique ID.
</Callout>

**Partner User ID is required to bulk import.**
