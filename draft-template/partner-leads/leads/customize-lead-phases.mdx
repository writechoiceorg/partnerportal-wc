## Customize your lead phases

1. Go to **Leads** in the sidebar and select **Configure**.
2. Scroll to the **Lead Phases** section.
3. Click the **pencil icon** to edit your lead phases.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388629593/4055add4fe13c742702211a5b874/image.png?expires=1779111900&signature=e81893c14c13615f871e0d70bf28c22104a564f6a67fc82657da874829560f73&req=diMvHs98lIRWWvMW1HO4zRmvjXRXCQvC2s1vyOOs0FDAi8lv3vCqBo07q%2BsT%0A%2Fz5J2zHkDCSRgiuXVWg%3D%0A)

From this section you can:

- Add new lead phases
- Delete unused lead phases
- Set a default phase for new leads

---

## Delete a lead phase

A phase can be deleted only if it is not currently in use.

A phase **cannot** be deleted if:

- A lead is currently assigned to it.
- It is set as the default phase.
- It is a required system phase (Closed Lost, Closed Won, or n/a).

To delete a phase, click the **trash icon** next to it.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388630544/ff99a12879ea6ca4acc9a0fab929/image.png?expires=1779111900&signature=a5d56ec71f13a57e52c646407a5b13c368b5decdb4bc8e4e0dc8b060e8c9e0d0&req=diMvHs99nYRbXfMW1HO4zW00Xxrrp27dVjssqVi0tCnWjMn2ZpjrjbQUCH98%0ANY3LSqfInifuAM29l4s%3D%0A)

<Callout type="warning">
  If you delete a phase that is mapped to your CRM, phase updates from the CRM will no longer apply to that phase, and a CRM error will be triggered instead.
</Callout>

## Set a default phase

The default phase determines which phase new leads start in when submitted. Leads remain in this phase while in **Pending** status.

To set a default phase, select the desired phase in the **Lead Phases** section.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388631439/cbd617fe8a37b42cc603578df9a3/image.png?expires=1779111900&signature=6ce135a6b4c8c8877576b59b5fc0494ef4a27389378440823efc3756d338dbdc&req=diMvHs99nIVcUPMW1HO4zXNtbFMcmzc5W3GkNRTdYX325U8o8Sv8seE7xe4d%0Amoqzbw6dxXn1sk%2FufhA%3D%0A)

<Callout type="info">
  If leads remain in Pending for an extended period, make sure your default phase reflects how you want those leads displayed.
</Callout>

---

## Lead expiration

A **Closed Lost** phase can trigger leads to expire automatically. If you prefer to expire leads manually, turn off the **"Trigger Leads to expire"** option.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2388632685/3f8811008aebac439c130aca060e/image.png?expires=1779111900&signature=0ef936b43d71104baee456429e1a32a2d3c4d8da294b16cd4214cdfce5277748&req=diMvHs99n4dXXPMW1HO4zVOKIjzAdRmyNGKv%2FdeplBDWQ2%2FM%2BqAd0EqZ3hh1%0AjoYIf5ENQeGSj2mon%2FA%3D%0A)

<Callout type="info">
  Any phase customization connected to your CRM will only apply once a lead has been mapped.
</Callout>
