## As an Admin

1. Go to **Partners** in the sidebar and select **All Partners**.
2. Locate the partner for whom you'd like to import users.
3. Scroll to the bottom of the page and find the **Partner Users** section.
4. Click **Add Partner User** and select **Import CSV**.
5. In the window that opens, download the CSV template if you haven't already.
6. Click **Select CSV file**, choose your file, and click **Import Partner Users**.
7. If errors are found, an error message will indicate what needs fixing. Correct the errors and re-upload the file.
8. Once the import is successful, all users will receive an email with instructions to set up their account.

<Callout type="info">
  For a visual walkthrough, check out the [step-by-step video guide](https://youtu.be/tIDcxbJurr0).
</Callout>

<Callout type="warning">
  If the link in a user's welcome email expires, they can request a password reset with [these steps](https://help.partnerportal.io/en/articles/8694347-how-to-reset-password) to complete their setup.
</Callout>

---

## As a Partner Owner

1. Go to **Account** in the sidebar and select the **Team** tab.
2. Click **Add Team Member** and select **Import CSV**.
3. Download the CSV template if you haven't already.
4. Select your CSV file and import your team members.
5. If errors are found, you'll see a message detailing what needs fixing. Correct any issues and re-upload the file.
6. Once the import is successful, all users will receive an email with instructions to set up their account.

<Callout type="warning">
  If the link in a user's welcome email expires, they can request a password reset with [these steps](https://help.partnerportal.io/en/articles/8694347-how-to-reset-password) to complete their setup.
</Callout>
