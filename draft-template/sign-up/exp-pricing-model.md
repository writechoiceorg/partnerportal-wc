# PartnerPortal.io Pricing Model

PartnerPortal offers three subscription plans. All plans include access to every current feature and integration — the difference between plans is the number of partners and leads supported.

---

## Plans

![Pricing plans overview](https://downloads.intercomcdn.com/i/o/j01nt7mc/2057182940/33491fac3e4da79c041a720cd11b/Screenshot+2026-02-12+at+9_46_32%E2%80%AFAM.png)

*Figure 1 — Overview of all available subscription plans.*

### Free

Get started at no cost with a limited number of partners and leads.

| | |
|---|---|
| **Partners** | 2 |
| **Leads** | 5 |
| **Price** | Free |

### Growth — $249 / month

For growing programs that need more capacity.

| | |
|---|---|
| **Partners** | 50 |
| **Leads** | 300 |
| **Price** | $249 per month |

### Enterprise — $499 / month

For programs that need unlimited scale.

| | |
|---|---|
| **Partners** | Unlimited |
| **Leads** | Unlimited |
| **Price** | $499 per month |

> ℹ️ **Note:** All plans include access to all current features and integrations. Plan limits apply to the number of active partners and leads only.
