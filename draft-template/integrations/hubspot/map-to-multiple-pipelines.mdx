---
title: "Map Leads to Multiple HubSpot Pipelines by Lead Type"
description: "Learn how to route leads to different HubSpot pipelines automatically based on the lead type set in your lead registration form."
---

When your partners submit leads, PartnerPortal.io can route each one to a different HubSpot pipeline based on a lead type field. This lets you separate leads by criteria such as business type, partner tier, location, or product.

**Who can do this:** Admins only

---

## Before You Start

- Admin access to PartnerPortal.io
- A HubSpot integration already connected and configured
- Multiple pipelines already set up in HubSpot

---

## Step 1: Create Lead Types in Your Registration Form

Lead types are configured as a drop-down field on your lead registration form.

1. Go to the **Accounts & Settings** tab and select the **Leads** sub-tab.
2. Click **Edit Options** next to **Type**.
3. Click the **+** button to add each lead type.

![Lead registration form settings showing the Edit Options button next to the Type field](https://downloads.intercomcdn.com/i/o/j01nt7mc/2377382132/8deebc4a0e38a6618319e74d0a9f/image.png?expires=1783016100&amp;signature=f99b5a10d4dd3c616b1df0ddd5969d5daea49b3370b604a7680ee01b68ba49f2&amp;req=diMgEcp2n4BcW%2FMW1HO4zciCl1gLcn6hvU0Nk1xor9Mt0y5bqSNjrbX%2FIQnE%0ABEdI1NqDRKQ%2BE8q%2Bzyw%3D%0A)

Common examples of lead types include:

- Type of lead (e.g., "New Business" vs. "Existing Client")
- Type of partner
- Partner location
- Type of product

---

## Step 2: Map Lead Types to HubSpot Pipelines

1. Go to the **Integrations** tab and open **Settings** under HubSpot.
2. Click **Configure** and find the **Pipeline** object.
3. Configure the Pipeline object as follows:

   | Setting | Value |
   |---|---|
   | **Type** | Portal Object |
   | **Field** | Type |

4. Click **Map Values**.

   ![HubSpot configuration showing the Pipeline object set to Portal Object with Field set to Type](https://downloads.intercomcdn.com/i/o/j01nt7mc/2377383570/04e772a03b1508232b19a1466948/image.png?expires=1783016100&amp;signature=0bb0c9cdc3f93e6823ffc0405201cdb7db2164e0a00e3f712ef537565f7f19c6&amp;req=diMgEcp2noRYWfMW1HO4zftclTWqVZ05EBp1ua4%2FtExihXNcuH4ts7EnYXry%0ATrnShSL%2B9uM70hncJbs%3D%0A)

5. For the **On Create set HubSpot Pipeline to** field, select **Map Manually**. This ensures each lead type routes to the correct pipeline when a lead is created or updated.
6. For each lead type listed, select the corresponding HubSpot pipeline from the dropdown.
7. Click **Save**.

   ![Map Values panel showing each lead type mapped to a corresponding HubSpot pipeline](https://downloads.intercomcdn.com/i/o/j01nt7mc/2377385350/2aa8bcd9b87914b7faf3163f9d65/image.png?expires=1783016100&amp;signature=b582ef3322b9719124813ca26588a43f08a9bcae4f2b1280e79938df8032d7ac&amp;req=diMgEcp2mIJaWfMW1HO4zctb4dFqfmzqnbFtjSlrghuFuNxDlyf6GCsJ5Qxz%0AG0zf1hfUl5JepnSH%2Bbw%3D%0A)

## Step 3: Map Deal Stages for Each Pipeline

Because the pipeline is sourced dynamically from the lead type, you need to map deal stages for each pipeline separately.

1. Find the **Deal Stages** object and click **Map Values**.

   ![HubSpot configuration showing the Deal Stages object with the Map Values button](https://downloads.intercomcdn.com/i/o/j01nt7mc/2377386412/5a06b148c95ad1080c18173f2d84/image.png?expires=1783016100&amp;signature=50ed76bb2bdc07a0bfb73b979e9cf15ee868cb8796e848dd9c02d5f4f51349a2&amp;req=diMgEcp2m4VeW%2FMW1HO4zRWE8qSgr8myqDloIcE0oQ21V9Y1X6uzh3fGJav3%0Adewn%0A)

2. Set the stage that all deals should start in when created in HubSpot. The **Map Manually** option is recommended to ensure the mapping is set to your preference.
3. On the left-hand side, select each lead type in turn and map the portal phases to the desired HubSpot stages for that pipeline.
4. In the **When HubSpot Deal is changed** section, complete the mapping for all pipelines so that partner portal phases update whenever you move a deal stage in HubSpot.

---

## Step 4: Copy Mappings Across Lead Types (Optional)

If multiple lead types share the same deal stage mapping, use the **Copy to All** button to apply the same mapping values to all lead types at once. This saves time when you have many lead types to configure.
