## To Embed a Video:

1. Navigate to an announcement you want to edit or create a new one clicking on **Add New** under the **Announcements** section on the sidebar.

2. In the text editor, select **Insert** and then click **Media**.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2364825584/c3002bdd1264b321deb93f43802b/image.png?expires=1783016100&amp;signature=15284d950d0f6e3bddd15a2a7900122b9349db23b6c484d745f6c4124306fd54&amp;req=diMhEsF8mIRXXfMW1HO4zUcBM8xuBUxb%2ByOI6laQUozBANkwvKq7xDbHNj2r%0AW0Wi%2BMeL0kNEwFY8wvE%3D%0A)

This will open the **Insert/Edit Media** window.

1. Select the **Embed** option.

2. Paste your embed code into the provided field.

3. Click **Save** when finished.

## Important Notes

- Supported video providers include **Vimeo and YouTube**.

- Embedded videos stream natively, so there is **no file size limit** when using embed code.
