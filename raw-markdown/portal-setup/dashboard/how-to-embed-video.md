## To Embed a Video:

1. Navigate to either the **Announcements** tab in your portal.

2. Select **Insert** and then click **Media**.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2172505520/f83c1257341c4f0c8a6483e07ce3/Screenshot%2B2024-06-26%2Bat%2B10_26_09-E2-80-AFAM.png?expires=1778093100&amp;signature=b9c105299f6ab2e20a685fafcf094860c88e843e06a31158b4ef833a1737284e&amp;req=diEgFMx%2BmIRdWfMW1HO4zVHXK6QXrFTOmcZxvnYltfSP4Hc4oNQquh0qBRJ7%0AA2N2KTMphF5w7o9sqxo%3D%0A)

This will open the **Insert/Edit Media** window.

1. Select the **Embed** option.

2. Paste your embed code into the provided field.

3. Click **Save** when finished.

![](https://downloads.intercomcdn.com/i/o/1094245655/0e3fa4941418ab4b87520f92/Screenshot+2024-06-26+at+10_26_18%E2%80%AFAM.png?expires=1778093100&amp;signature=620d9902e9e40a8503eef9dea73d17fabf039f71422b5d8000a9f45eea327c16&amp;req=dSAuEst6mIdaXPMW1HO4zYUFLMuWzPUWs4AvElqlwXfr1w1JuHzptITKon1e%0AFmxYN1KZUuAUiD%2FD4%2FA%3D%0A)

## Important Notes

- Supported video providers include **Vimeo and YouTube**.

- The upload size limit for files added directly to the portal is **100MB**.

- Embedded videos stream natively, so there is **no file size limit** when using embed code.
