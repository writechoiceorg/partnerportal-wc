As a Portal Admin or Owner, you can invite your Partner's team members to the portal on their behalf. To do so, follow these steps:

1. Navigate to the **Partners** tab and select the respective Partner.

  ![](https://downloads.intercomcdn.com/i/o/1177752957/880d019db026bd2bbe5cb0d6/Screenshot+2024-09-12+at+9_05_12%E2%80%AFAM.png?expires=1783016100&amp;signature=76bdc870cebd802bef61523c2a30f0bcb0948870249c15aac25e63a7da0ce33b&amp;req=dSEgEc57n4haXvMW1HO4zXe1Hpc1xeto91QABwwjjlNbrlqreXdySLzPeXrn%0AXtc7%0A)

2. Scroll to the bottom of the screen and click the **Add Partner User** button.

  ![](https://downloads.intercomcdn.com/i/o/1177753296/50249b667c6d30595402590a/Screenshot+2024-09-12+at+9_05_21%E2%80%AFAM.png?expires=1783016100&amp;signature=a368856ad116cf49793290116d054541c1bb4caf07a162d5f4391dd5ccf12171&amp;req=dSEgEc57noNWX%2FMW1HO4zaEeG%2BEFpea4qZGoqGwXGcspDDC5zIIlY01g5TuS%0AHASv%0A)

3. Enter the required information for the team member:

  - First Name

  - Last Name

  - Email Address

  - Phone Number (must include the country code and be 11 digits long)

**Note:** If a valid phone number is unavailable, you may use any 11-digit number temporarily.

Once the information is entered, click **Submit** and wait a few seconds for confirmation. A success message will appear at the top of the screen, indicating that the invitation has been sent.

# Note on Duplicate Emails

The portal does **not** support duplicate emails, meaning a single email address cannot be attached to multiple partner(or partner user) accounts. If a partner user needs to be added under a partner account but has already registered with that same email, the system will prevent adding a duplicate account.

**What to do if a duplicate email has been registered:**

- If a partner user accidentally registered with the wrong partner account, the registered duplicate partner account will need to be updated to an invalid email address.

- This update can only be done by our team. Please contact our support team at [support@partnerportal.io](<>) with the Duplicate Partner(Company) Name and the user's email address, and we will make the necessary changes.

Once the duplicate account is updated to an invalid email, then the correct account can be registered without issues.

# **Partner User Final Account Set Up**

After being invited, team members will receive an email with instructions to set up their password and complete the account registration.

**Important:** The invitation link to create a password is time-sensitive. If the link expires, the team member can request a password reset by following the steps in the email.

After the initial email is sent to the team member, please inform them, that they'll have *limited time* to complete their account setup (create a password) If the link to create a password expires, the team member will need to request a password reset link with [these steps](https://help.partnerportal.io/en/articles/8694347-how-to-reset-password).

***For more information on how to update the Partner User permissions, check out the following [article](https://help.partnerportal.io/en/articles/9800890-how-to-update-partner-user-roles-permissions-as-an-admin).***
