# **How It Works**

- **Portal-Wide Translation**:
Once enabled, the entire portal is translated into the selected language. This includes menus, buttons, and user interface elements.

  - To select a language, click on the menu in the bottom right corner.

      ![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2381761555/f324d0e28d8883248c9e6272bba5/image.png?expires=1779111900&amp;signature=ff9abf39b5b4eb35e41d34a702bb396c55f7ae36f1d41598dd0b3ad91289f764&amp;req=diMvF854nIRaXPMW1HO4zX7cmbPZ8MW138MvkybOzXOPZJjBH4bZT8Omyqwe%0A3kSa%0A)

- **Automatic Translation Based on Browser Settings**:
If a user’s browser is set to one of the supported languages and the Multi-Language Feature is enabled, the portal will automatically display in their preferred language—no manual adjustments needed!
