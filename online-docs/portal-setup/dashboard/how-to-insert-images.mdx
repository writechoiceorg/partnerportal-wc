# Hosting the Image

The first thing you'll want to do is source your desired image on a 3rd party site such as [imgbb](<>) or [imgur.com](https://imgur.com/upload). Images cannot be uploaded within the portal, and they'll need to be uploaded and sourced elsewhere. (example screenshots below)

![](https://downloads.intercomcdn.com/i/o/687711977/311bd76ca06c5815007ef8b0/Screenshot+2023-03-09+at+11.35.06+AM.png?expires=1778093100&amp;signature=be4d9a7d56c816b417a67d305012f7cdccd27a5ee76e64c375a533f0f196f075&amp;req=ciggEch%2FlIZYFb4f3HP0gDb1QbuYYRnovO9teXAok6A8MTqsQQ4Mq%2FnFgYdN%0A1uGxnA3XVrt4U%2F5N0Q%3D%3D%0A)

Once your image has been uploaded, right-click on the image and select **Copy Image Address**.

# Inserting an Image

Images can be inserted into a Resource description, an Announcement, an Opportunity, or the Lead Comments.

Head to the portal in one of the areas mentioned above, and click on **Insert** and select **Image**.

![](https://downloads.intercomcdn.com/i/o/687713237/f07d42f10eb3e9380653a3b5/Screenshot+2023-03-09+at+11.38.45+AM.png?expires=1778093100&amp;signature=90182301ab15b4a7d22c19d4d6b9bfec08f40cf5992fbc789592c97a079f812a&amp;req=ciggEch9n4JYFb4f3HP0gMKgTRLu3FUtz6czfpgd7E93VWKt4wOEkRNRLQ%2Bl%0A3YkXPpL21DEgWUA%2FgQ%3D%3D%0A)

Paste the copied Image Address in the *Source* field. Adjust the image size as needed.

![](https://downloads.intercomcdn.com/i/o/687713953/d177ee5fa835b147b4925447/Screenshot+2023-03-09+at+11.39.03+AM.png?expires=1778093100&amp;signature=0eb955223c4195bd50da364ae6af569cd19c35f82cd83b80f9edcaf080e80f91&amp;req=ciggEch9lIRcFb4f3HP0gACDLu1Negw7Iip%2Fe6ROgUfZuG39cbtJf3bfLJOJ%0AO9q0s%2FAIrIBctXV0yg%3D%3D%0A)

Enter any desired text and select the Save button.

![](https://downloads.intercomcdn.com/i/o/687714120/498a8d3b53a8871d2b45cc37/Screenshot+2023-03-09+at+11.40.16+AM.png?expires=1778093100&amp;signature=ff16fa79ca676659f095dd2656d6df09c860a31e1bae950f9a64a42cc96d82a1&amp;req=ciggEch6nINfFb4f3HP0gFJR7cyx7gG1VIkvehoCBppmLsX7SbT2%2BSpab1nB%0AXgOzHfqtJeKKfN7G%2Fg%3D%3D%0A)

You have successfully added an image to your portal. For more information on the Announcements tab, head to this [article](https://help.partnerportal.io/en/articles/6931947-announcements).
