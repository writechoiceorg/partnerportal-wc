**Reseller Permissions Overview**

Reseller Permissions allow partners to update the portal on your behalf, reducing manual work. This feature is currently available only with our HubSpot CRM integration and is not compatible with other CRMs.

# Enabling on Two Way Sync

Go to the **Integrations** tab, select **HubSpot Settings**, and click **Configure**.

Scroll down to the *Other Settings* section, locate the **Two-Way Sync** option and enable it. This allows editing of Phase, Close Value, and Close Date in the portal, syncing changes back to HubSpot.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2374978066/7f6f7b90da0337eb38a7f662bab4/image.png?expires=1783016100&amp;signature=d9133dd0e9f380952b11c06d1663ed54bdf508690afbf938bd0f3f09a7746480&amp;req=diMgEsB5lYFZX%2FMW1HO4zRD0%2BdL1ggZUXA5WLV%2F25IRmWIeu97VVJJjOHmR1%0Ajs4NecIGEYjVyiRBXHY%3D%0A)

Scroll up to the **Deal Stage** field and click **Map Values**.

- In the **When Portal Phase is changed** section, map which HubSpot stage you want deals to update to when a portal phase changes (e.g., Lost = Closed Lost).

- Below, map which portal phase updates when a HubSpot stage changes.

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2375017913/5f21cff576a42c12a9d6a438a020/image.png?expires=1783016100&amp;signature=75752ae2313ad56d5c56a01ef04c2f609f3bfdf23b900e1d51c064f6f39f1a6e&amp;req=diMgE8l%2FmoheWvMW1HO4zfkBXviYatNCmlpI%2FWXq38zWj1i2dRNdFvZND6Io%0A%2F2Nt%2FPmbTRurt2NhAis%3D%0A)

Please make sure that the "*On Create set HubSpot Deal Stage to"* field has been mapped before saving.

# Enabling Reseller Permissions

- With Two-Way Sync enabled and Portal Phases mapped, go to the **Partners** tab and select the desired partner.

- Click **More Details**, scroll to the **Permissions** section, and toggle Reseller Permissions on/off.

*(Note: Only portal owners and admins can enable this.)*

![](https://downloads.intercomcdn.com/i/o/j01nt7mc/2375021323/8301c50230854ef740ff9dcd2593/image.png?expires=1783016100&amp;signature=77b58fe04cf92e09e776d3cdeb5ac31e15c38f6b4f105751a2b5b339ef97bd19&amp;req=diMgE8l8nIJdWvMW1HO4zb8E8LFwJlStdszg%2Fm8cCWZwXYViJ0wgK%2FI0Wt3U%0Awsvj4YxNF3G5iJxZ%2FvI%3D%0A)

Once enabled, the partner and their users can update Portal Phases on your behalf.
